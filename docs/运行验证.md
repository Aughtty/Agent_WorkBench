## 4. 检索评测

```powershell
python scripts/evaluate_retrieval.py
```

| Backend | Mode | Hit@3 | MRR@3 |
|---|---|---:|---:|
| TF-IDF | BM25 | 1.0000 | 0.9167 |
| TF-IDF | Vector | 1.0000 | 0.9417 |
| TF-IDF | Hybrid | 1.0000 | 0.9417 |
| BGE | BM25 | 1.0000 | 0.9167 |
| BGE | Vector | 1.0000 | 0.8750 |
| BGE | Weighted Hybrid | 1.0000 | 0.9417 |

共 20 条固定 query/source。初版 BGE 等权 Hybrid 的 Hit@3 为 0.95，漏掉“如何避免智能体无限循环”；把 BM25/Vector RRF 权重设为 1.4/1.0 后恢复到 1.0。

结论：在当前术语明确的小数据集上，神经 Embedding 没有自动优于词法/TF-IDF 基线。该评测用于回归与参数选择，不代表开放领域性能。

## 8. 真实 Debug 记录

### `ModuleNotFoundError: workbench_agent`

原因：`src/` 布局尚未执行可编辑安装。入口增加 `src` 兜底；标准方式仍是 `pip install -e .`。

### Windows 中文乱码

原因：`conda run` 捕获输出与终端编码不一致。批处理设置 UTF-8，直接 Python 验证正常。

### Agent 评测退出后 SQLite 临时文件占用

业务结果已生成，但 Windows 清理临时目录报 WinError 32。评测临时目录使用 `ignore_cleanup_errors=True` 后退出码为 0。

### 神经模型依赖过重

`sentence-transformers` 会引入约 124 MB PyTorch wheel，下载缓慢。最终改用 FastEmbed + ONNX 运行 BGE，保留 CPU 能力并避免 PyTorch 依赖。
