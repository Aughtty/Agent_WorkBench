# 项目面试风险清单

概率表示面试官看到简历后的追问概率，不表示问题难度。

## 高概率

| 风险问题 | 你必须说明的事实 | 常见错误 |
|---|---|---|
| 为什么需要 Agent | 工具组合动态；固定部分仍用 Workflow | 把任何 LLM 调用都称为 Agent |
| Tool Calling 如何工作 | Schema → tool_calls → 执行 → role=tool → 再决策 | 说模型直接执行 Python |
| 你自己实现了什么 | 主循环、Registry、RRF、Chunk、Memory、评测 | 把 BGE/FastAPI 功能说成自研 |
| Chunk 为什么 500/80 | 当前文档的可解释初始值，需要更多实验 | 声称是最佳参数 |
| Embedding 是什么 | BGE 把文本映射到 512 维向量，项目没有训练模型 | 把 TF-IDF 与神经 Embedding 混为一谈 |
| 为什么 Hybrid | BM25 精确词项 + BGE 不同措辞；RRF 融合排名 | 说向量一定优于 BM25 |
| Top-K 怎么选 | 用 Hit@K、MRR、回答质量、Token/延时权衡 | 越大越好 |
| 是否用了向量数据库 | 没有；是进程内向量索引 + SQLite Chunk | 写“自主实现向量数据库” |
| Memory 怎么实现 | session 隔离、12 条窗口、字符预算 | 写“长期记忆” |
| 评测是否可信 | 20/8 条自建回归集，只证明当前场景 | 把 100% 写成通用准确率 |

## 中概率

| 风险问题 | 回答方向 |
|---|---|
| 工具参数错误怎么办 | JSON Schema 完整校验，错误作为 Observation |
| 模型重复调用怎么办 | Prompt 约束、最大 6 步、Trace 识别；可继续加调用缓存 |
| 429/5xx 怎么处理 | 指数退避；401/400 不重试 |
| 为什么不用 LangChain/LangGraph | 为学习和解释协议显式实现循环；复杂状态图时再用 LangGraph |
| 为什么 SQLite | 单机低运维、事务可靠；高并发迁 PostgreSQL |
| 如何处理 PDF | pypdf 文本提取；扫描 PDF 需要 OCR，目前不支持 |
| 如何避免文件越权 | 文件工具固定根目录；上传使用安全文件名和临时目录 |
| 新文档为什么重建索引 | 小数据的简单可靠取舍；大规模使用增量 Vector DB |
| Trace 是否泄密 | 不记录 Key；生产还应脱敏用户内容和工具结果 |

## 低概率但容易问穿

| 风险问题 | 回答方向 |
|---|---|
| BGE 如何训练 | 只需了解对比学习思想；明确项目没有训练它 |
| RRF 公式 | 每个排名贡献 `weight/(k+rank)`，项目 k=60 |
| BM25 公式 | TF、IDF、文档长度归一化；不必死背全部推导 |
| 多进程部署索引一致性 | 当前进程内索引不支持可靠多进程热更新，这是局限 |
| Token 统计为何可能为空 | 依赖学校网关是否返回 usage |
| FastAPI 是否真异步 | 上传读取是 async；Agent/Embedding 当前同步，生产需线程池/任务队列 |

## 答辩红线

- 不说“生产级”“高并发”“高可用”。
- 不说训练了模型或自研向量数据库。
- 不隐瞒小评测集。
- 不把使用一个库等同于掌握其底层全部实现。
- 被问到局限时直接说明，并给出迁移方案。
