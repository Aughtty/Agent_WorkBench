# LLM 应用工程

LLM 应用需要处理网络超时、鉴权失败、限流、服务端错误、模型返回无效 JSON、工具参数错误和工具执行异常。适合重试的通常是网络瞬时错误、HTTP 429 和部分 5xx；鉴权失败或参数错误不应盲目重试。

Trace 应记录会话、用户输入、模型轮次、工具名、参数、执行结果、模型耗时、工具耗时和最终答案，同时避免记录 API Key 等敏感信息。Trace 用于 Debug、评测和成本分析。

自动测试不应真实调用付费模型。单元测试可以使用 Scripted Model 或 Fake Client，稳定覆盖工具循环、异常、协议解析和停止条件；少量端到端测试再调用真实服务。

FastAPI 把 Agent 封装成 REST 服务。健康检查用于确认服务和知识库状态；接口层应校验输入长度、文件类型和上传大小，并把上游模型故障转换成明确的 HTTP 错误。
