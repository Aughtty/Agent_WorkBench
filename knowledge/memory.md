# Agent Memory

Agent Memory 是让系统利用历史信息的机制。短期记忆通常保存当前会话最近消息；长期记忆可能保存跨会话用户偏好、事实或历史任务。数据库只是存储实现，不等于已经设计好 Memory 策略。

不能无限把全部历史消息发送给模型，因为上下文窗口有限，历史越长 Token 成本和延时越高，还会引入无关信息。常见策略包括消息窗口、字符或 Token 预算、历史摘要和相关记忆检索。

多用户或多会话系统必须使用 session_id 或 user_id 隔离记忆，避免不同用户的消息互相泄露。本项目采用 SQLite 保存消息，并按 session_id 查询最近窗口。
